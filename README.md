# Poster King

Free Gujarati, Hindi and English festival, daily wishes and suvichar poster maker.

## Features
- 13 poster categories
- Custom name, message, photo, background color
- PNG download and native share
- Small Poster King watermark
- Installable PWA

## Deployment
Publish the repository root with GitHub Pages. The app is static and runs in the browser.

## Not yet included
Secure admin backend, daily remote template publishing, Android APK and live AdSense/AdMob integration are future development tasks.
